1. The Bound Anthology

2. Creadores:
* Brandon Isaac Miranda Montes
* Mia Reneé Valenzuela Yescas
* Gloria Jesus Sanchez Lopez

3. Descripción: Es una novela visual de terror. Trata sobre cómo varias personas viven el duelo después de un evento traumático, y al final todas las historias se conectan. Ahorita es solo el prototipo para armar la lógica del juego, así que todavía no es un juego completo. Detalle importante es que de lo disponible hubo una actualizacion, pero lo que se muestra en el trabajo original y lo que se mostrará aqui serán dos esqueletos: Un scroll y un simulación de un libro.

4. Configuraciones e Instrucciones
Programa usado: Unity (versión 2022.3.10f1).

Cómo puedes checarlo?
  1. Abre la carpeta del proyecto en Unity 2022.3.10f1.
  2. Como apenas son las bases, no se "juega" con controles normales.
  3. Solo dale clic al botón de "Play" arriba en el editor para verlo correr.
